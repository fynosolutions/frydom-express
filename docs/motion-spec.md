# 动效与降级

参考来源：Hey Noodles 公开首页 HTML、当前公开 CSS/JS 与用户执行文件记录。已核实其开场为全屏底色、跳色文字、Canvas 像素图片逐级清晰后淡出。以下参数为 Frydom 的自有实现，不宣称与参考站时序完全相同。没有复用其业务内容或整套主题代码。

| ID | 实现 | 触发/参数 | 手机/减少动态/故障 |
| --- | --- | --- | --- |
| M01 | 中英文首页品牌开场 | 原橙棕全屏底色；FuturaPT 的 LOADING… 文字跳色；真实餐品图按 8/16/32/80/160/480px 六级像素采样渐清；850ms 开始淡出，1120ms 隐藏，1200ms 独立故障兜底 | 点击 Skip intro 或 Escape 结束；减少动态跳过；初始 HTML 遮罩 hidden，JS 禁用不会覆盖正文；不等待图片、字体或第三方模块结束才关闭 |
| M02 | 首页品牌滚动带 | CSS transform，29 秒周期；两份视觉短语，其中副本 aria-hidden；暂停/继续按钮；离屏暂停 | 减少动态停止；脚本失败为静态，不自动隐藏正文 |
| M03 | 全站吸顶导航 | sticky；滚动 20px 后增加阴影，约 200ms 过渡 | 手机用原生 details/summary，关闭 JS 也可展开；Escape 与外部点击关闭 |
| M04 | 首页文字与食物分层 | 文字整体 20px 入场，600ms；照片倾斜、手写装饰、品牌贴纸 | 中文独立排版；H1 为连续真文本；无脚本默认可见 |
| M05 | 桌面食物轻视差 | rAF + passive scroll；仅大于 950px、首屏范围内，最多 20px；scale 1.02 | 手机停用；减少动态停止；不影响按钮和正文 |
| M06 | 全站文字滚动入场 | 标题、段落、列表及餐品文字组进入视口后渐显上移；IntersectionObserver threshold .08，底部预留 5%；桌面 28px/680ms，手机 18px/560ms，同批 65ms 错开且最多延迟 195ms；每组只播放一次 | Web Animations API；待入场内容默认可见；减少动态时立即取消正在播放的效果，恢复静态；API 缺失与脚本错误均保留正文；不拦截滚动 |
| M07 | 卡片/CTA 反馈 | 图片 scale1.03、位移3px；按钮上移3px；150–220ms | focus-visible 对应反馈；触屏无需 hover 读取事实 |
| M08 | 手机人气推荐横向列表 | 原生 overflow、scroll-snap；前后按钮和键盘可聚焦区域；不自动播放 | 无脚本保留原生滑动，隐藏依赖脚本的按钮；完整菜单始终是全部分类正文 |
| M09 | 普通页间链接 | 不启用拦截导航的过渡 | 深层路径刷新、浏览器返回和无脚本导航保持原生行为 |
| M10 | 顶部导航文字放大 | 支持 hover 的精细指针悬停时，标签以 240ms 过渡放大至 1.1 倍；移开平滑恢复；键盘 focus-visible 同样生效 | 只缩放文字，链接点击区域和相邻布局不变；触屏无悬停依赖；减少动态保持静态文字 |

`prefers-reduced-motion: reduce` 下停用所有动画、视差和过渡，滚动使用即时定位。动画初始化失败不会隐藏正文。持续滚动有明确暂停控制。开场期间短暂限制滚动，并在所有关闭路径和离开页面时恢复；没有全页滚动劫持、canvas 业务正文或逐字拆分 H1。Canvas 只绘制装饰餐品图。

开场在每次首页完整进入/刷新时播放，站内锚点不会重复触发，内页不播放。它的计时与关闭不依赖主应用模块。自动化还验证了主模块被阻断与开场图片加载失败时正常结束。逐帧预览见 `screenshots/home-opening.gif` 与 `qa/intro-animation.json`。

验证：浏览器检查四种宽度、减少动态、阻断模块脚本和关闭 JavaScript，全部事实正文保留；截图见 `screenshots/`，执行结果见 `qa/browser-verification.json`。
