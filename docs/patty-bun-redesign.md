# Frydom Express 全站视觉改版

## 确认的范围

2026-10-28 经两轮设计问答及最终确认，采用接近 Patty & Bun 的配色、整体视觉、内容编排和交互方式。保留 Frydom Logo、原文字和图片、中英文内容、24 条业务页面地址及表单功能。此前字号增量、导航 2.5 倍和餐品图 70% 的规则由本次布局取代。

## 实现

- 配色为奶油色 `#F9ECD2` 与红色 `#E52B2B`。参考站使用 Adobe Typekit 的 Cooper Black 和 ITC American Typewriter；项目采用开源 Fraunces 与 Courier Prime 近似其复古粗标题和打字机正文风格，字体本地托管并附 OFL 许可。中文使用系统宋体系列回退，平台字形可能不同。
- 桌面居中字标、四个主入口（菜单、活动、门店、加盟）与“更多”（故事、支持）；Logo 返回首页，政策在页脚。手机采用红底全屏菜单、X 开关、Escape 关闭、焦点循环及背景 inert，原生 details 保留无脚本使用能力。
- 首页先展示现有餐品、门店和新品素材组成的三幅影像，再进入活动、菜单及门店区域。原首页品牌故事和环球风味正文及图片移入故事页的 `BrandDetails.astro`，首页保留品牌入口。
- 菜单改为居中分类标题、大幅透明餐品图与三列名称/描述/价格；手机单列，分类条吸顶。
- 活动总览使用三列无外框图文，手机单列；完整福利档位与套餐内容留在详情页。继续使用从用户 PDF 提取的独立图片，不展示整张海报。
- 门店、故事、加盟、总部支持及政策页统一字体、颜色、间距和图片形式；保留完整业务内容与表单提交约束。
- 动态包括可跳过且有 1200ms 兜底的首页开场、首次滚动文字/图片入场、可暂停滚动文字、导航和图片悬停反馈、手机导航开合。减少动态设置会取消动画，脚本失败时正文仍可见。

## 参考依据与边界

已查看首页、菜单、活动、门店及门店详情，并实际验证手机菜单开合。活动/菜单三列、配色与参考站字体来自页面与 CSS 观察。参考首页桌面曾停留于 opacity:0 状态，因此没有声称复现其精确加载时序；项目使用有兜底的独立动效实现。未引入参考站图片、视频、文字或商业字体。

参考页：https://www.pattyandbun.co.uk/ 、https://www.pattyandbun.co.uk/menu 、https://www.pattyandbun.co.uk/offers 、https://www.pattyandbun.co.uk/locations 。

- `npm run build` 成功，24 条业务路由及 404 正常生成。

- 全套浏览器检查 153 项：151 项通过后，修复 320px 英文支持页长标题和首页推荐箭头溢出；对应 2 项复测全部通过。覆盖 320/390/768/1440px、无 JavaScript、减少动态、导航、活动和表单模拟。修复后的构建与静态检查再次通过。
- `src/data/site.json` 与本轮改版前逐字一致。页面文本核对：英文 617 条、中文 604 条均在相应语言页面内保留；每种语言 42 个原图片引用均保留。该核对允许内容在页面之间迁移，记录在 `docs/qa/redesign-content-preservation.json`。
- 桌面与手机截图：`docs/screenshots/redesign/`。运行时截图和浏览器模拟不代表已部署到线上。

## 维护

`src/styles/redesign.css` 是本轮视觉样式，优先于旧基础样式；`src/components/BrandDetails.astro` 保存迁移的首页品牌内容。菜单和活动业务数据仍统一在 `src/data/site.json`。本轮没有部署，也没有修改菜单价格或活动条件。
