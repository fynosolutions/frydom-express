# 新品与优惠更新

新增中英文 `/offers.html`、`/staff-offer.html`、`/leg-quarter.html`、`/chicken-bucket.html`（英文加 `/en` 前缀）。首页首屏之后展示三个活动，主导航与页脚新增活动入口。菜单新增手枪腿、炸鸡桶以及活动详情链接；Brooklyn 门店新增团餐入口。

活动内容统一维护于 `src/data/site.json` 的 `locales.zh.offers` / `locales.en.offers`。对应新增餐品价格维护于同语言 `menu`。从三份 PDF 的内嵌图片图层直接提取餐品、吉祥物和玩偶，保留透明通道并导出 WebP；不再使用整张海报。团餐拆成三个档位卡片，手枪腿拆成独立产品图、价格与卖点，炸鸡桶拆成餐品组合、数量说明与盲盒赠品区域。标题、价格和规则均为网页文字。

团餐限定海报列出的 Brooklyn 地址及电话，保留工作证件要求与充值卡限制。其他活动未擅自指定参与门店或期限。炸鸡桶保留海报组合原文，份量、配菜选择与盲盒供应引导购买前咨询。本次没有调整原有大菜单价格。

验证：构建成功，24 条业务路由的 137 项静态检查通过。浏览器首轮 156 项中 154 项通过；两项旧检查写死了新增前的餐品数量及分类栏滚动距离，更新为数据数量和元素位置后，相关 3 项复测全部通过。覆盖四种屏宽、活动跳转、中英文切换、无脚本内容和门店入口。桌面及手机截图位于 `docs/screenshots/offers/`，最终复测记录位于 `docs/qa/offers-regression.json`。
