## 修改

1. `.menu-item .item-photo img` 宽度 70%，上下左右内边距同比缩小，保持图像比例。适用于完整菜单及首页推荐，不缩小首页大图。原素材、清晰度及来源没有被替换。
2. 新增 `HomeIntro.astro`：原品牌色开场、跳色文字、餐品 Canvas 像素渐清、淡出。每次首页刷新重播，内页不显示。允许跳过；约 1120ms 结束，1200ms 独立兜底；无脚本/减少动态直接显示正文；不等待网络资源无限加载。
3. 从当前参考站 CSS 核实 FuturaPT，为所有英文元素加载 Book/Medium/Bold/ExtraBold。图像中不可编辑的既有品牌文字保持原素材。字体来源与文件记录见 `sources/reference/font-manifest.json`。
4. 114 处标题字号声明 +5px，242 处正文/界面字号声明 +2px，包括各响应式断点。CSS 变量、品牌文字、导航、滚动带、按钮与输入字体均统一。页脚装饰性超大品牌文字按新字体宽度适配。
5. FuturaPT 字宽更宽，针对长词添加可选换行位置，保留名字/标题原文本；平板支持服务网格改为三列，手机两列；城市名保持放大字号并调整字重与字距。

## 精确对比

初版测量保存在 `qa/revision-baseline.json`。浏览器在 320、390、768、1440px 分别测量英文首页、英文菜单、中文菜单，共 12 组，验证正文 +2px、Heading +5px、FuturaPT 字体，以及菜单图片宽高均为原来的 0.70。

开场测试验证显示、品牌底色、像素步骤、1200ms 上限、跳过、Escape、刷新重播、仅首页、减少动态、无脚本、图片错误、应用模块阻断等路径。逐帧数据 `qa/intro-animation.json` 记录 0→5 像素阶段，以及 1120ms 隐藏状态。

全站回归仍覆盖 16 个中英文页面、四个宽度、无脚本、链接、表单与内容一致性。最终结果汇总于 `acceptance.md`，原始报告为 `qa/browser-verification.json`。
