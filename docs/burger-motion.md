# 首页汉堡顺序动效 · 2026-11-10

本地修改，未部署。

- FRYDOM 保留加宽字形，字距恢复为原来的 -.02em，移除此前为疏排添加的左内边距，并恢复原 30vw / 最大 432px 展示尺度。
- 汉堡沿透明抠图轮廓添加黑色细边，保留原柔和投影；不使用矩形边框。后续按用户要求将各方向描边从 1px 减至 0.6px（减细 40%）。
- 移除旧固定延时 CSS 动画。heading-motion.ts 在 FRYDOM 字标动画实际完成后启动汉堡动画：从 12% 放大至 100%，时长 1000ms。后续加入透明度 0→1，与缩放共用 smoothstep 进度，起止平滑且同步完成，避免先放大后显现；等待字标时完全透明。最新调整将汉堡动画起点设为字标动画的精确结束时间，不添加延时或额外帧间隔；桌面和手机回归均验证两者时间点一致。
- 慢图等待图片 load 后再播放；开启减少动态效果、调整窗口或离开页面会结束动画，恢复完整图片。默认无脚本状态直接显示完整图片。
- 用独立 scale 属性避免和图像居中 translate、现有滚动处理发生冲突。动画只播放一次，无持续循环。

验证：构建、127 项静态检查通过；初版通过 20 项针对性浏览器回归，最终 1 秒无间隔版本通过 8 项相关回归。新增用例检查先字标后汉堡、精确衔接时间、1000ms 时长、透明度与缩放同步、黑边、完成状态、减少动态效果与窗口调整时的取消。已有用例覆盖四种宽度、中英文、无 JavaScript 和动效脚本受阻。Impeccable 首页扫描无发现。
